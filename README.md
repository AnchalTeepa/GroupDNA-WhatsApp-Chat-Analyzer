# 🧬 GroupDNA — WhatsApp Chat Analyzer

A Python and NumPy-based tool that analyzes WhatsApp group-chat data to identify activity patterns, response behaviour, frequently used words, silent streaks and participant personality archetypes.

## ⚙️ Project Constraints

The project was intentionally developed using Python fundamentals.

### Allowed

* Python fundamentals
* Strings and string methods
* Lists and dictionaries
* Loops and conditional statements
* Functions
* File I/O
* NumPy
* Datetime

### Not Used

* Pandas
* Matplotlib
* Seaborn
* Plotly
* Regular expressions
* `collections.Counter`
* `collections.defaultdict`
* NLTK
* Scikit-learn
* Pre-built WhatsApp-analysis libraries

## 🗓️ Seven-Day Build Log

| Day | Work Completed |

## 🚀 How to Run the Project

1. Download or clone this GitHub repository.
2. Open `GroupDNA_Anchal.ipynb` in Google Colab or Jupyter Notebook.
3. Run the library-import cell.
4. Upload `hostel_bois.txt` when prompted.
5. Run all cells from top to bottom.
6. View the complete GroupDNA report at the end of the notebook.
